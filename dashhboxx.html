DashhBoxx

A fast-paced multiplayer first-person shooter with team deathmatch and free-for-all. You can sprint, jump and slide around the arena during matches.

How it plays

DashhBoxx has team deathmatch and free-for-all. Sprinting, jumping and sliding give you ways to move around the arena during a fight. The controller collects movement and camera input, while the server runs the match countdown.

First-person camera

Mouse input steers the camera. The vertical angle is limited and sent to the other players.

FastActionPlayerController.cs
private void UpdateLook()
{
    Vector2 mouse = Mouse.current.delta.ReadValue() * mouseSensitivity;
    transform.Rotate(0f, mouse.x, 0f, Space.Self);
    pitch = Mathf.Clamp(pitch - mouse.y, -82f, 82f);
    if (rig.cameraPivot) rig.cameraPivot.localRotation = Quaternion.Euler(pitch, 0f, 0f);
    AimPitch.Value = pitch;
}

Movement input

The four movement directions are combined into one vector. Clamping its length keeps diagonal movement from getting a speed boost.

FastActionPlayerController.cs
Vector2 input = Vector2.zero;
if (FastActionPlayerUI.Held(FastActionPlayerUI.Left)) input.x -= 1f;
if (FastActionPlayerUI.Held(FastActionPlayerUI.Right)) input.x += 1f;
if (FastActionPlayerUI.Held(FastActionPlayerUI.Back)) input.y -= 1f;
if (FastActionPlayerUI.Held(FastActionPlayerUI.Forward)) input.y += 1f;
input = Vector2.ClampMagnitude(input, 1f);

Match countdown

The countdown uses the server clock so the match can start at the same time for everyone.

FastActionPlayerStats.cs
private void BeginCountdown()
{
    Phase.Value = MatchPhase.Countdown;
    PhaseEndsAt.Value = NetworkManager.Singleton.ServerTime.Time + startCountdown;
}
