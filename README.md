# Portfolio

Static portfolio website for Mads Hoogeveen.

## GitHub Pages

The website files are in the repository root, with lowercase filenames matching
the links in the HTML. No build step is needed.

In GitHub, open **Settings → Pages** and select:

- **Source:** Deploy from a branch
- **Branch:** main
- **Folder:** / (root)

After committing and pushing changes, GitHub Pages publishes the site at
https://luxin079.github.io/Portfolio/.
